Photo dates and time zones: why a photo shows the wrong day or hour

A photo taken at 2:34 pm shows 12:34 am. A video is a day out. A whole folder shows the day you copied it. All of this comes down to a few different “dates” stored in different places.

One photo, several dates

  • The date taken, inside the picture (EXIF). Written by the camera, as the clock on the wall showed. It usually has no time zone, and newer cameras add a separate offset.
  • The date in a video file (QuickTime). By convention it is stored in UTC, the universal clock. A video shot at 2:34 pm in Mongolia is stored as 06:34 UTC, and apps that forget to convert show the wrong hour.
  • The file's own dates, which Finder shows as Created and Modified. They are set by the file system, not the camera. Copying, downloading, converting or restoring a file can set them to the day it happened.
  • The date in the file name, such as 20120630143447.mp4 or IMG_20190704_123456.jpg. Most phones and many cameras write the time into the name, in local time.
  • Google Takeout's JSON date, a number of seconds since 1970 in UTC.

Why the hour is wrong

If a tool writes a local time as if it were UTC, or the other way round, the result is out by your time zone difference. For example, 14:34 written as UTC and read back in a time zone ten hours ahead shows 00:34 the next day, which puts the picture on the wrong day.

Why the day is wrong

  • The file dates were reset by a copy, so the library falls back on the day you copied.
  • There was no date inside, and the app used the file date.
  • The camera clock was wrong, or a time zone was never set on holiday.

What a good fix does

  1. Use the best source. The date inside the picture first, then Google's JSON, then the file name, then the folder name. Never make up a date when a real one exists.
  2. Fill, do not overwrite. Only add a date when one is missing, and say where it came from.
  3. Handle the time zone properly. Store local time with the right offset, using the picture's location when it has one.
  4. Show before and after for a few real photos before anything is written, and write the result into a copy.

That is what Photo Clinic's Fix my photos does. Its preview lists exactly which files have no date stored inside, the date Finder shows for each, and the date that would be stored (for example the one in the name), so you can decide whether to trust the names.
