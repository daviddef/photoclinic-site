How to tell if two photos are really duplicates

Two photos with the same name might be different pictures. Two with different names might be the same picture. Here is how to decide, and which kinds are safe to remove.

Last reviewed 26 October 2026. Written by the Photo Clinic team from what we learned moving large photo libraries. See how we write these guides.

Four kinds of “the same”

  1. Exact copies. The files are identical, byte for byte. They may have different names or sit in different folders (IMG_0042.jpg, IMG_0042 (1).jpg). One can be removed with no loss.
  2. The same picture at a different size or quality. A smaller copy, a re-saved copy, or a copy exported by another app. The pictures look alike, but the files are different, and one is better.
  3. An original and an edit. The same photo after cropping, filters, or red-eye fixes. You may want both.
  4. RAW and JPEG pairs. A camera that saves both makes two files with the same name. They are not duplicates: the RAW is the negative, and the JPEG is the picture made from it.

Why names and sizes are not enough

  • Cameras restart their numbering, so two different photos can both be called IMG_1234.jpg.
  • Copies get names like (1) added when a file with the same name already exists.
  • Two files can have the same size by chance, so size alone is not proof.
  • Re-saving a photo changes its size without changing how it looks.

How exact copies are found

The reliable test is the content. A good tool groups files by size first (cheap), then compares a fingerprint of the content, and confirms the whole file before calling two files identical. Photo Clinic does this, keeps the first copy and moves the others into a spare folder. It does not delete them, and you can see both pictures side by side before you decide.

How look-alikes are found

For pictures that are the same but not identical, the tool compares how they look, using a small fingerprint of the picture's shape and brightness. Two photos whose fingerprints are close are probably the same picture. It is a good hint and a poor judge, so the right answer is to show them side by side, suggest a keeper (for example the larger one, or the one you marked as a favourite), and let you choose.

Which to keep

  • A favourite, or one with an edit, usually wins.
  • Otherwise the one with more pixels and the larger file.
  • The one with more information inside (date, place, caption).
Move aside first, delete later. Move the extras into a folder, look through your library for a while, then delete the folder when you are sure. That is how Photo Clinic works, and you can check again afterwards that nothing is left.
