Unzip on a Synology NAS, so the zips are not pulled over the network.

  • Unzip on the NAS. If your zips are on a Synology NAS you opened as a network drive, the Unzip step can ask the NAS to unpack them itself. Sign in once with an account made for Photo Clinic; the password is kept in your Mac's Keychain. The step explains how to make the account.

1.0.124

7 November 2026

The Photos check no longer sends photos Photos already has under a copy number.

  • Photos already holding a photo as IMG_1 (2).JPG is recognised. A second import gives a photo a copy number, so the check saw it as missing, sent it again, and Photos refused it with Unknown error. The check now ignores the copy number when the size is the same.
  • A copy-number match must also have the same capture time. The time is read from the file and compared with Photos, allowing for time zones. A file with no readable time is not counted as already there, so a wrong match cannot leave a photo out.
  • The result says how many photos were matched this way.

1.0.119

7 November 2026

Importing into Photos only remembers what Photos really took.

  • Files Photos refuses are no longer remembered as imported. Before, every file sent to Photos was written to the list of finished files, even when Photos showed a Cannot Import box. That list now holds only the files Photos confirmed, so running again tries the rest.
  • A batch that mostly fails stops the run. If Photos does not add half or more of a batch, Photo Clinic stops with a plain message and the list of files, instead of working through thousands more.
  • Network drives are copied to your Mac first. When the folder you are importing sits on a network drive, each batch is copied to a temporary folder on your Mac and imported from there, because Photos reads a network share badly. The copy waits for a drive that stops answering and carries on.
  • First check what Photos really has. A new setting on the Copy to your Photos library step compares the files Photo Clinic says it sent with Photos' own records and forgets the ones Photos does not have, so they are sent again. The old list is kept beside it.

Unzip waits for a network drive that drops and carries on.
